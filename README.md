# Tongkai Wu's Homepage

Personal academic homepage for Tongkai Wu, using a lightweight Jemdoc-style layout.

## Structure

- `index.html`: the published page and its content
- `jemdoc.css`: typography and academic-page styling
- `middle-layout.css`: centered layout and responsive behavior
- `static/assets/img/photo.jpg`: profile photo
- `static/assets/favicon.ico`: browser icon
- `contents/`: content files retained from the previous template for reference

The site is fully static and can be deployed directly with GitHub Pages. It does not require a build step or third-party JavaScript at runtime.
